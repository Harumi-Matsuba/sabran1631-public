# 方法

[English](METHOD.en.md)

## 資料と鍵
- 暗号文：BnF fr. 4134（Sabran の1633年の帳簿の写し）。Gallica ark:/12148/btv1b9060193z の f100・f108・f115・f121・f122・f139・f140・f146・f154。openapi.bnf.fr の IIIF から原寸で取得しました。
- 鍵：George Lasry 氏の再構成 "BNF Francais 4134"（2022-05-25）。友清理士氏の Cryptiana GL.htm に画像で載っています。これを記号名（形の近い英数字）で書き写しました（`data/key.tsv`）。文字52記号、語の数字19、重ね記号1です。0・34・29 は Lasry 氏の表で「o- 34 29. ET」と並んでいるので、3つとも et と読みました。これは書き写した側の解釈です。

## 書き起こし
1. ページの傾きを、行の墨の投影が最も鋭くなる角度で見積もって直しました。そのうえで行を切り出しました。f. 54r だけは傾きが約2度あり、最初の切り出しでは行が混ざったため、直してから切り直しています。
2. Claude が、行画像を拡大して記号名で書き起こしました（`data/transcription_first.tsv`）。

## 食い違いを、画像で直す（corrections/）
OpenAI Codex に、こちらの読みを見せずに、同じ行画像を書き起こさせました。こちらと1対1で食い違う記号は、別の2つの AI（Codex と Claude Sonnet）に、それぞれ答えを見せずに画像で判定させました。直したのは、**2つが同じ別の名前を選んだ所だけ**です。

| 周 | 判定の仕方 | 直した数 |
|---|---|---|
| r1 | 行画像の中で、問う位置を [?n] で伏せた並びを示す。見本は鍵の画像から切り出した記号（値は載せない） | 26 |
| r2 | r1 と同じ。Codex の書き起こしに見本の画像を添えた | 17 |
| r3・r4 | 記号を1つずつ切り出し、前後の文脈なしで判定する。位置は、目盛りを重ねた行画像で Codex に答えさせた | 16・4 |
| r5・r6 | r3 と同じ。見本に、この写字生の実例を名前ごとに最大4つ加えた。実例は、こちらと Codex が同じ名前を付けた記号から選んだ | 5・2 |

直した所には、語らしくなった所（intelligence、commis、l'argent）と、かえって崩れた所（f. 46v ie les excite→ieleseecite、f. 57v compagnons→cimpagnons ほか、[OPEN.md](OPEN.md)）の両方があります。2つのモデルが一致しても、誤りは残ります。

## 独立の2回目（second/）
書き起こしを最後に直した後、新しい文脈で Codex に3回、書き起こさせました。渡したのは、行画像（116枚）と、見本の画像2枚（鍵の記号と、この写字生の実例）と、記号名の一覧（`second/PROMPT.md`）だけです。値・こちらの読み・鍵・判定の結果は渡していません。実行記録はどの回も返答1件だけで、コマンドの実行やファイルの読み込みはありません。

一致率は、こちらの記号のうち、行ごとの記号の並びの一致ブロックに入った割合です（`src/compare.py`）。3回の値（全体）は 92.6%・92.1%・88.1% でした。葉ごとには、3回のうち最も低い値を README に載せています。3回目は f. 50v で pl の多くを r と書き、その葉が 76.2% になりました。

直すのに使った比較（上の各周）は、独立とは呼びません。

## 対照（controls/）
文字の値を鍵の記号のあいだでかき混ぜた鍵を、1000通り作りました。本物の鍵と比べて、平文のフランス語らしさを見ます。フランス語らしさは、wordfreq の仏語上位5万語から作った文字3連の対数尤度の平均です。語の数字・重ね記号・読めない記号・読みの不確かな記号で、連なりを区切りました。9葉とも、本物以上は 0/1000 でした。

## 較正（calib/）
この帳簿の見た葉には、当時の解読の書き込みがありません。そこで、同じ鍵で Lasry 氏が解読した BnF Baluze 155 f. 79（Gallica btv1b9001401d f163）の暗号17行を使いました。Lasry 氏の解読（GL.htm の画像の赤字）を `calib/lasry_plain.tsv` に書き写して、答えにしています（599文字。Lasry 氏が値を書いていない記号は除きました）。

| 手順 | 一致 |
|---|---|
| Claude Sonnet の書き起こし（答えを見ずに、見本の画像つき） | 78.6% |
| ＋文脈つきの判定（Codex と Sonnet、r1 と同じ方法、直した36） | 82.5% |
| ＋記号を1つずつ切り出した判定（r3 と同じ、直した37） | 86.1% |
| ＋実例を加えた見本での切り出し判定（r5 と同じ、直した2） | **86.1%**（`calib/transcription_f79.tsv`） |
| 参考：Codex だけ（実例つきの見本）3回 | 87.0%・82.6%・88.3% |

**対象の葉の手順との違い**（較正の値にどう効くかは測れていません）：
- 最初の書き起こしの書き手：対象は Claude Opus（このリポジトリの作り手）、較正は Claude Sonnet です。Opus は較正の答え（Lasry 氏の解読）を先に見てしまったため、較正の葉を書き起こせませんでした。
- 判定の周の数：対象は文脈つき2周と切り出し4周、較正は文脈つき1周と切り出し2周です。対象では、後の周ほど直す数が減りました（26→17→16→4→5→2）。
- 見本の実例：対象の写字生（fr. 4134）の手から取りました。Baluze 155 f. 79 は別の手なので、較正では「別の写字生の実例」として渡しています。
- 傾きの補正：較正の葉は補正していません。

このため 86.1% は、対象の手順の正確さを近似するものとして示します。Sonnet だけの書き起こし（78.6%）から判定を重ねると上がること、Codex だけでは 82.6〜88.3% とばらつくことは、上の表のとおりです。

## 値の付いた割合
`src/decode.py` で、記号名が鍵にある記号の割合を数えました（882/897、98.3%）。値があっても語にならない所は、READING と OPEN に印を付けています。

## 限界
- 人は書き起こしを確かめていません。
- 記号名と形の説明、見本の切り出しは、こちらで作りました。別の AI とこちらが同じ誤りをしている箇所は、照合では見つかりません。
- fr. 4134 は写しの帳簿です。写すときの誤りは区別できません。
- fr. 4135（1635年）にも同じ鍵の暗号がありますが、写字生の字形が違い、このリポジトリでは読んでいません（[OPEN.md](OPEN.md)）。
