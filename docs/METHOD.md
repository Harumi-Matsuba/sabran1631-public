# 方法

[English](METHOD.en.md)

## 資料と鍵
- 暗号文：BnF fr. 4134（Sabran の1633年の帳簿の写し）。Gallica ark:/12148/btv1b9060193z の f100・f108・f115・f121・f122・f139・f140・f146・f154。openapi.bnf.fr の IIIF から原寸で取得しました。
- 鍵：George Lasry 氏の再構成 "BNF Francais 4134"（2022-05-25）。友清理士氏の Cryptiana GL.htm に画像で載っています。これを記号名（形の近い英数字）で書き写しました（`data/key.tsv`）。文字52記号、語の数字19、重ね記号1です。0・34・29 は Lasry 氏の表で「o- 34 29. ET」と並んでいるので、3つとも et と読みました。これは書き写した側の解釈です。

## 書き起こし
1. 行の墨の投影で行を切り出しました。f. 54r だけは傾きが約2度あり、最初の切り出しでは行が混ざったため、傾きを直してから切り直しています。
2. Claude が、行画像を拡大して記号名で書き起こしました（`data/transcription_first.tsv`）。

## 食い違いを、画像で直す（corrections/）
OpenAI Codex に、こちらの読みを見せずに、同じ行画像を書き起こさせました。こちらと1対1で食い違う記号は、別の2つの AI（Codex と Claude Sonnet）に、それぞれ答えを見せずに画像で判定させました。直したのは、**2つが同じ別の名前を選んだ所だけ**です。

| 周 | 判定の仕方 | 直した数 |
|---|---|---|
| r1 | 行画像の中で、問う位置を [?n] で伏せた並びを示す。見本は鍵の画像から切り出した記号（値は載せない） | 26 |
| r2 | r1 と同じ。Codex の書き起こしに見本の画像を添えた | 17 |
| r3・r4 | 記号を1つずつ切り出し、前後の文脈なしで判定する。位置は、目盛りを重ねた行画像で Codex に答えさせた | 16・4 |
| r5・r6 | r3 と同じ。見本に、この写字生の実例を名前ごとに最大4つ加えた。実例は、こちらと Codex が同じ名前を付けた記号から選んだ | 5・2 |
| r7 | r1〜r6 で直した60か所を、もう一度1つずつ切り出し、「直す前」と「直した後」の2択で判定（どちらが元かは示さない）。2つが同じ名前を選べばそれに、割れたら直す前に戻す | 戻した16（割れた13、2つとも直す前3） |

直した所には、語らしくなった所（intelligence、commis、l'argent）と、かえって崩れた所の両方がありました。r7 で compagnons・deux などは戻りましたが、f. 46v ie les excite→ieleseecite のように、2択でも2つのモデルが直した後を選んだ所は残っています（[OPEN.md](OPEN.md)）。2つのモデルが一致しても、誤りは残ります。

## 独立の2回目（second/）
書き起こしを最後に直した後、新しい文脈で Codex に3回、書き起こさせました。渡したのは、行画像（116枚）と、見本の画像3枚（鍵の記号と、この写字生の実例を名前ごとに最大8つ、ページが散るように選んだもの）と、記号名の一覧（`second/PROMPT.md`）だけです。値・こちらの読み・鍵・判定の結果は渡していません。実行記録はどの回も返答1件だけで、コマンドの実行やファイルの読み込みはありません。

一致率は、こちらの記号のうち、行ごとの記号の並びの一致ブロックに入った割合です（`src/compare.py`）。3回の値（全体）は 92.2%・92.3%・92.5% でした。葉ごとには、3回のうち最も低い値を README に載せています。

同じ最終の書き起こしを、実例が最大4つの前の見本で3回読ませると、92.1%・86.5%・86.4% でした（`second/earlier_sheet_*`）。この3回では、1回の中で同じ記号の名前がそろって入れ替わることがありました（f. 50v の pl をすべて r、ほかの葉の S をすべて f など）。見本の実例を増やしたのは、このためです。前の見本の3回も含めて最低を取ると、葉ごとの最低は f. 50v 72.1%、f. 57v 81.2%、f. 54r 81.8%、f. 66r 84.6% になります。

直すのに使った比較（上の各周）は、独立とは呼びません。

## 対照（controls/）
文字の値を鍵の記号のあいだでかき混ぜた鍵を、1000通り作りました。本物の鍵と比べて、平文のフランス語らしさを見ます。フランス語らしさは、wordfreq の仏語上位5万語から作った文字3連の対数尤度の平均です。語の数字・重ね記号・読めない記号・読みの不確かな記号で、連なりを区切りました。9葉とも、本物以上は 0/1000 でした。

## 較正（calib/）
この帳簿の見た葉には、当時の解読の書き込みがありません。そこで、同じ鍵で Lasry 氏が解読した BnF Baluze 155 f. 79（Gallica btv1b9001401d f163）の暗号17行を使いました。Lasry 氏の解読（GL.htm の画像の赤字）を `calib/lasry_plain.tsv` に書き写して、答えにしています（599文字。Lasry 氏が値を書いていない記号は除きました）。

この帳簿の読みと同じ手順で読みました。
1. 最初の書き起こし：Lasry 氏の解読を見ていない Claude Opus に、鍵の画像・鍵の記号名の一覧・行画像（51枚）だけを渡して作らせました（`calib/opus_first.tsv`、依頼文 `calib/opus_first_PROMPT.md`）。実行記録で、渡したファイル以外を開いていないことを確かめました。
2. この帳簿の r1〜r7 と同じ7周の判定を、Codex と Claude Sonnet で行いました（`calib/opus_rounds/`）。食い違いを探す Codex の書き起こしも、この帳簿と同じ種類の依頼（見本なし・見本つき・実例つき）で取りました。

| 段階 | 一致 |
|---|---|
| 最初の書き起こし（Claude Opus、答えを見ずに） | 90.2% |
| r1・r2 文脈つきの判定（直した36・31） | 91.0%・91.5% |
| r3・r4 切り出し判定（直した7・3） | 92.2%・91.7% |
| r5・r6 実例つきの見本での切り出し判定（直した4・0） | 92.0%・92.0% |
| r7 直した所の2択での再判定（戻した16） | **92.0%**（`calib/transcription_f79.tsv`） |
| 参考：Codex だけ（実例8つの見本）3回 | 83.5%・85.1%・87.3% |

残る違い：
- 見本の実例は、この帳簿（fr. 4134）の写字生の手から取りました。Baluze 155 f. 79 は別の手なので、較正では「関連する帳簿の別の写字生の例」として渡しています。
- この帳簿の最初の書き起こしをした Claude Opus は、作業の中で鍵の値を知っていました。較正の Opus にも鍵の画像（値つき）を渡しています。
- 傾きの補正は、どちらも f. 54r 以外ではしていません。

**前の道筋（参考）：** 最初の書き起こしを Claude Sonnet に作らせた道筋では、78.6%（書き起こしのまま）→ 82.5% → 86.1% → 84.6%（2択の後）でした（`calib/sonnet_route_*`、`calib/r1_context.tsv` ほか）。最初の書き手の違いが、最後の値に大きく効くことが分かります。

## 書き起こしの範囲
暗号の記号の連なりを書き起こしました。平文の中に点で囲んで単独で書かれた符号（. H.、.12. など）と、書き手が消した所は含めていません。

## 値の付いた割合
`src/decode.py` で、記号名が鍵にある記号の割合を数えました（879/891、98.7%）。値があっても語にならない所は、READING と OPEN に印を付けています。

## 限界
- 人は書き起こしを確かめていません。
- 記号名と形の説明、見本の切り出しは、こちらで作りました。別の AI とこちらが同じ誤りをしている箇所は、照合では見つかりません。
- fr. 4134 は写しの帳簿です。写すときの誤りは区別できません。
- fr. 4135（1635年）にも同じ鍵の暗号がありますが、写字生の字形が違い、このリポジトリでは読んでいません（[OPEN.md](OPEN.md)）。
